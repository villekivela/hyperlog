# Shoulder press machine (`shoulder_press`)

## Movement and exercises served
Seated overhead press on two lever arms loaded by one weight stack. Hands start at shoulder height and push up and slightly together.
- `machine_shoulder_press`.

One machine: the bar grip versus the neutral grip is a hand-position choice, not a different movement.

## Motion
- Left arm and right arm: each a lever that pivots at the back of the machine (assumed from the machine type; unverified), moving the grip in an arc up and in. Whether the arms move independently is not stated; Hammer Strength calls its machines iso-lateral elsewhere but this page does not say so.
- Range of motion: the page says only "Seat position provides range-of-motion adjustments", so the start height is set by the seat. No degrees are published.
- Both arms load the 95 kg stack through cable and pulleys.

## Adjustments and fit rules
- Seat height sets the start position of the stroke (page text). Rule to confirm at Hukka: grips level with the shoulders or slightly above at the start.
- Grip choice: bar grip or neutral grip (page).
- Red indicator marks the axis of rotation; the placard asks the user to align with it.
