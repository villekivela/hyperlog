# Pec deck / rear delt combo (`pec_deck`)

## Movement and exercises served
Seated horizontal adduction (pec fly) on two lever arms that swing in a horizontal plane about vertical axes, loaded by one weight stack. The same machine serves the rear-delt fly (horizontal abduction) with the user facing the pad, or with the arms set to the rear start position.
- `pec_deck`: seated, back on pad, forearms or handles forward, arms sweep together in front of the chest.
- `reverse_pec_deck`: same arms, user turned to face the pad (chest on pad), arms sweep apart behind the shoulders.
- `1_arm_reverse_pec_deck`: as above with one arm moving; the arms are independent levers, so one arm is simply left at rest.

One machine, no variants: arm pads vs handles is a hand-position difference, not a movement difference.

## Motion
- Left arm and right arm: each revolute about a vertical axis (axis marked with a red indicator on the machine, per the Life Fitness page), mirrored left and right, sweeping in a horizontal plane.
- Range of motion: not published. The page only says a five-position adjustable start mechanism sets the start angle. Degrees need to be measured at Hukka.
- Both arms pull the one selectorized weight stack (138 kg) through cable and pulleys. The arms are not geared together on the evidence of the page; the fitshop text says "adjustable motion arms", which suggests independent levers (unverified).
- Seat: height adjusted by a roller mechanism (Life Fitness page). Fitshop text says the seat can be turned 180 degrees to switch to reverse fly; unverified for this model.

## Adjustments and fit rules
- Seat height so the upper arms are level with the shoulders (typical pec deck placard rule, unverified for this model).
- Start position: five-position arm start; pick the position where the arms are slightly behind the shoulder line.
- Red axis indicator: align the shoulder with it (stated on the page: it is a cue for correct alignment).
- Built-in foot bar for stabilisation.
