# Hyperlog

A native Android app that runs periodized strength programs, logs what happened, and coaches you
when the plan meets real life.

- [`GLOSSARY.md`](GLOSSARY.md) — the domain's words.
- [`docs/adr/`](docs/adr/) — architecture decisions.
- [`docs/research/`](docs/research/) — progression, partials, and logging UX research.
- [`docs/design/`](docs/design/) — the logging screen design and test reports.
- [`docs/programs/`](docs/programs/) — the starter program.
- [`docs/development.md`](docs/development.md) — toolchain, phone, prototype and legacy notes.
- [`brand/`](brand/) — logo and icon sources.

Work is tracked in [GitHub issues](https://github.com/villekivela/hyperlog/issues).
