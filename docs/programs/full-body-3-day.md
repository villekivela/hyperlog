# Hyperlog Full Body — 3 days, 12 weeks

An original program written for Hyperlog. It's the owner's first program in the new app and the
starter program the app ships with.

## Who it's for

An experienced lifter returning from a break caused by hand pain. They train three days a week
across three commercial gyms and prefer **low volume, high intensity** (Nippard Min-Max style).
The goals are hypertrophy and a **100 kg barbell bench press**.

## Bench goal

The estimate is about 93 kg. The owner reports 70 kg × 10 for two comfortable sets (about 2 RIR),
which Epley on reps + RIR puts at 93–98 kg. 10-rep sets overestimate, so the low end is used.
The last logged session was 65 × 10, 10, 7 on 2026-09-19. 100 kg is +7%, realistic for this
cycle, and the week-12 top single is the attempt.

The bench is the only lift with more than one exposure a week:
- **Day A:** heavy top set and back-off sets.
- **Day B:** close-grip bench for triceps and lockout.
- **Day C:** one hard volume set and one back-off set.

That makes about 7 hard bench sets a week.

## Principles

- **Few sets, taken hard.** Each exercise has 1–2 working sets. Early sets are @ 1 RIR, and the
  last set goes to 0 RIR (failure) on isolation exercises, and on compounds where failing is safe
  (machines, Smith, DB).
- **Barbell bench and RDL never go to failure.** The top set is @ 1 RIR.
- **Warm-ups are generated by the app**, ramping from the first working set's weight. Heavy lifts
  get 3–4 ramp sets, isolation exercises 1.
- **About 6–8 hard sets per major muscle a week**, each muscle trained 2–3 times.
- **Mostly machines, cables and dumbbells**, with alternatives in every slot so all three gyms work.
- **Long muscle lengths are preferred** (stretch-biased exercises, lengthened partials).
- **Effort is in RIR, and weights come from automatic progression.** The program never prescribes
  a load. A back-off set's weight is the top set's weight minus about 10%, rounded down to a rung.

## Blocks

| Weeks | Block | What changes |
| --- | --- | --- |
| 1–2 | Ramp-in | Override: every target is +1 RIR, there's no failure and no techniques. |
| 3–6 | Build | As written. The last sets go to failure. Techniques start on the marked exercises. |
| 7–11 | Intensify | Main lifts: the top set drops to 3–5 reps @ 1 RIR. Techniques stay. Isolation exercises unchanged. |
| 12 | Deload + test | Days B and C: one set fewer, @ 3 RIR, no techniques. Day A: bench top single (below), then deload. |

**The week-12 bench test:** work up to a top single. If the week-11 estimate is 97 kg or more, the
single is 100 kg; otherwise it's a single @ 1 RIR, which sets a hard data point. Deload sets never
lower the estimate. The top single updates it.

## Rest

- Main lifts (bench, squat pattern, RDL, row): 3:00.
- Everything else: 1:30–2:00.
- `SPEC.md`'s rest rules apply on top of this: no rest before drops, a breathing countdown between
  myo mini-sets, and no rest between superset partners.

## First coaching case: training around hand pain

The owner starts this program with sore hands. That is the first real job for the coach (spec:
Coaching → Rules; situation "pain in an area", area "hands/grip"). It should produce this Change,
for weeks 1–2 (or until "hands OK" is reported):

- **Swaps to remove or reduce gripping:**
  - Barbell bench → Smith machine bench press (or machine chest press if gripping the bar still hurts).
  - Close-grip bench → machine chest press.
  - DB incline press → incline machine press.
  - Barbell RDL → 45° hyperextension (no grip at all).
  - DB / barbell curls → machine preacher curl or Bayesian cable curl with a loose grip.
- **Pulls:** keep pulldowns and rows, with straps and a hook-free, open-hand grip; chest-supported
  only.
- **Load:** −10% on any exercise that kept a grip. All targets +1 RIR, and no drop sets on grip
  exercises.
- **Pain rule:** pain during a set stays at 3/10 or less and isn't worse the next morning. If it is
  worse, that exercise moves to its no-grip swap for the rest of the Change's scope.

Lower body and machines are untouched, so training continues at nearly full intensity. Bench
progress is mostly kept through the Smith machine bench. The barbell returns when the hands allow;
the estimate for barbell bench stays separate from the Smith machine bench, because they are
different equipment.

## Notes for the program file

- Exercise IDs must match the exercise library: `barbell_bench_press`, `close_grip_bench_press`,
  `smith_machine_bench_press`, `hack_squat`, `leg_press`, `2_grip_lat_pulldown`,
  `machine_pulldown`, `seated_leg_curl`, `lying_leg_curl`, `cable_lateral_raise`,
  `overhead_cable_triceps_extension`, `barbell_rdl`, `45_hyperextension`,
  `chest_supported_machine_row`, `leg_extension`, `machine_shoulder_press`, `bayesian_cable_curl`,
  `machine_preacher_curl`, `reverse_cable_crossover`, `db_incline_press`,
  `incline_machine_press`, `pec_deck`, `triceps_pressdown`, `seated_calf_raise`, and the listed
  alternatives. Use the cleaned library's ID wherever duplicates were merged.
- **Top set and back-off** is new to the program format. A back-off set is "same exercise, weight =
  top set − 10%, rounded down to a rung". The program-import ticket covers it, and progression
  judges the top set.
- The bench goal isn't part of the program file. It's a lift goal set in the app.
- **Slot notes carry the program-specific cues:**
  - Bench: "same grip, setup and pause every rep".
  - RDL and pulldowns: "use straps".
  - Row: "chest on the pad, pull with the elbows".
  - Presses and curls: "control the stretch, 1 s pause at the bottom".

## The program file

The app ships this program as `app/src/main/assets/programs/full-body-3-day.json`, in the program
format (`docs/program-format.md`). `StarterProgramTest` checks it against this document. Where the
document and the format don't line up, the file does this:

- **Blocks.** Each block writes Days A, B and C in full. Ramp-in repeats Build's days with a block
  override for weeks 1–2: `rirAdd: 1` (so 0 RIR becomes 1, and nothing goes to failure) and no
  techniques. Intensify writes its lower reps into its own days.
- **Techniques on the last set.** A slot with two sets and a technique is two lines, the second
  carrying it. Myo-reps and drop sets use the format's defaults (mini-sets of 3, up to 5; drops of
  25%, 2 of them). Lengthened partials go to failure.
- **Week 12, Day A.** The bench test is one line, 1 rep @ 1 RIR. Its weight is suggested from the
  estimate like any new rep range. The format prescribes no loads, so the 100 kg rule (estimate of
  97 kg or more) is in the slot's note. The rest of Day A is written as its deload: Build's first
  sets @ 3 RIR, one set fewer, no techniques. A day override can't do this, because a day's
  `rir: 3` would also set the single to 3 RIR.
- **Week 12, Days B and C.** Build's days with a day override: `rir: 3`, no techniques,
  `fewerSets: 1`. "One set fewer" takes the last set off each slot, and a slot with one set keeps it.
- **Rest.** Main lifts (both benches, close-grip bench, hack squat, leg press, RDL, row) rest
  3:00. Pulldowns, the shoulder press and the DB incline press rest 2:00; everything else 1:30.
- **Slot notes.** Close-grip bench gets the bench note. The shoulder press, DB incline press and
  both curls get the press and curl note.
- **Not in the file**, because the app owns them: warm-ups, the "deload sets never lower the
  estimate" rule, superset rest and the bench goal.
