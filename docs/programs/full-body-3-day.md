# Hyperlog Full Body — 3 days, 12 weeks

An original program written for Hyperlog, and the starter program the app ships with.

## Who it's for

An experienced lifter, perhaps returning from a break, who trains three days a week in one or more
commercial gyms and prefers **low volume, high intensity** (Nippard Min-Max style). The goals are
hypertrophy and a **barbell bench press goal**, such as 100 kg.

**Time budget:** two ~55-min days and one ~45-min day, from the first warm-up set to the last set.
Days A and B are the long days, and Day C the short one.

## Bench goal

The goal is a lift goal set in the app, for example a 100 kg bench. A goal about 5–8% above the
current estimate is realistic for one 12-week cycle; from a 94 kg estimate, 100 kg is +6%. When the
estimate comes from 10-rep sets, take the low end of the Epley range, because high-rep sets
overestimate. The week-12 top single is the attempt.

The bench is the only lift with more than one exposure a week:
- **Day A:** heavy top set and back-off sets.
- **Day B:** close-grip bench for triceps and lockout.
- **Day C:** one hard volume set and one back-off set.

That makes about 7 hard bench sets a week.

## Principles

- **Few sets, taken hard.** Each exercise has 1–2 working sets. Early sets are @ 1 RIR, and the
  last set goes to 0 RIR (failure) on isolation exercises, and on compounds where failing is safe
  (machines, Smith, DB).
- **Barbell bench and RDL never go to failure.** The top set is @ 1 RIR.
- **Warm-ups are generated by the app**, ramping from the first working set's weight. Heavy lifts
  get 3–4 ramp sets, isolation exercises 1.
- **About 6–8 hard sets per major muscle a week**, each muscle trained 2–3 times. Side delts get
  3 sets over two days (Day A, Day B), and calves 2 sets, on Day A.
- **Mostly machines, cables and dumbbells**, with alternatives in every slot so any commercial gym works.
- **Long muscle lengths are preferred** (stretch-biased exercises, lengthened partials).
- **Effort is in RIR, and weights come from automatic progression.** The program never prescribes
  a load. A back-off set's weight is the top set's weight minus about 10%, rounded down to a rung.

## Blocks

| Weeks | Block | What changes |
| --- | --- | --- |
| 1–2 | Ramp-in | Override: every target is +1 RIR, there's no failure and no techniques. |
| 3–6 | Build | As written. The last sets go to failure. Techniques start on the marked exercises. |
| 7–11 | Intensify | Main lifts: the top set drops to 3–5 reps @ 1 RIR. Techniques stay. Isolation exercises unchanged. |
| 12 | Deload + test | Days B and C: one set fewer, @ 3 RIR, no techniques. Day A: bench top single (below), then deload. |

**The week-12 bench test:** work up to a top single. If the week-11 estimate is within 3% of the bench
goal (97 kg for a 100 kg goal), the single is the goal weight; otherwise it's a single @ 1 RIR, which sets a hard data point. Deload sets never
lower the estimate. The top single updates it.

## Days

Values are for Build. "Techniques" apply to the last set only, from week 3.

### Day A — Heavy bench, squat, pulldown (~57 min)

| # | Exercise | Alternatives | Working sets | Techniques / Intensify |
| --- | --- | --- | --- | --- |
| 1 | Barbell bench press | Smith machine bench press | Top set 1 × 4–6 @ 1, then back-off 2 × 8–10 @ 1 | Intensify: top set 1 × 3–5 @ 1, back-offs stay 8–10 |
| 2 | Hack squat | Leg press, Smith machine squat | 1 × 6–8 @ 1, then 1 × 8–10 @ 0 | Intensify: 1 × 5–7 @ 1, then 1 × 8–10 @ 0 |
| 3 | 2-grip lat pulldown (straps) | Machine pulldown, 1-arm cable pulldown | 2 × 8–10 @ 0 | Lengthened partials |
| 4 | Seated leg curl | Lying leg curl | 1 × 8–10 @ 1, then 1 × 8–10 @ 0 | Lengthened partials |
| 5a | Cable lateral raise | Machine lateral raise, DB lateral raise | 2 × 10–12 @ 0 | Myo-reps |
| 5b | Overhead cable triceps extension | Overhead DB triceps extension | 1 × 10–12 @ 0 | Drop set (2 drops) |
| 6 | Seated calf raise | Standing calf raise, leg press calf press | 2 × 12–15 @ 0 | Lengthened partials |

5a and 5b are a superset.

3a and 3b are a superset, and so are 5a and 5b. Rest after the pair. Day C's chest fly is now
Day B's cable flye, and the calf raise is on Day A.

## Rest

- Main lifts (bench, squat pattern, RDL, row): 3:00.
- Everything else: 1:30–2:00.
- `SPEC.md`'s rest rules apply on top of this: no rest before drops, a breathing countdown between
  myo mini-sets, and no rest between superset partners. Rest is taken after the pair, so Day C's
  pulldown and DB incline press rest 2:00 once, after the incline press.

## First coaching case: training around hand pain

A worked example for the coach: a lifter starts this program with sore hands and tells Claude
"my hands hurt" on the Coach screen (spec: Coaching; ADR 0003). A good reply is this Change, for
weeks 1–2 (or until "hands OK" is reported). In Ramp-in, the program's own +1 RIR already covers the
effort, so the swaps are what matters:

- **Swaps to remove or reduce gripping:**
  - Barbell bench → Smith machine bench press (or machine chest press if gripping the bar still hurts).
  - Close-grip bench → machine chest press.
  - DB incline press → incline machine press.
  - Barbell RDL → 45° hyperextension (no grip at all).
  - Cable shoulder press → machine shoulder press.
  - Bayesian cable curl → machine preacher curl (a loose grip, or none), and no drop sets.
- **Pulls:** keep pulldowns and rows, with straps and a hook-free, open-hand grip; chest-supported, or
  the seated cable row with straps.
- **Load:** −10% on any exercise that kept a grip, and no drop sets on grip exercises. No extra
  RIR: Ramp-in's +1 already holds for weeks 1–2. Later in the program, +1 RIR on everything.
- **Pain rule:** pain during a set stays at 3/10 or less and isn't worse the next morning. If it is
  worse, that exercise moves to its no-grip swap for the rest of the Change's scope.

Lower body and machines are untouched, so training continues at nearly full intensity. Bench
progress is mostly kept through the Smith machine bench. The barbell returns when the hands allow;
the estimate for barbell bench stays separate from the Smith machine bench, because they are
different equipment.

## Notes for the program file

- Exercise IDs must match the exercise library: `barbell_bench_press`, `close_grip_bench_press`,
  `smith_machine_bench_press`, `hack_squat`, `leg_press`, `2_grip_lat_pulldown`,
  `machine_pulldown`, `seated_leg_curl`, `lying_leg_curl`, `cable_lateral_raise`,
  `overhead_cable_triceps_extension`, `barbell_rdl`, `45_hyperextension`,
  `chest_supported_machine_row`, `leg_extension`, `cable_shoulder_press`, `cable_flye`,
  `bayesian_cable_curl`, `machine_preacher_curl`, `reverse_cable_crossover`, `db_incline_press`,
  `incline_machine_press`, `triceps_pressdown`, `seated_calf_raise`, and the listed alternatives. Use the cleaned library's ID wherever duplicates were merged.
- **Top set and back-off** is new to the program format. A back-off set is "same exercise, weight =
  top set − 10%, rounded down to a rung". The program-import ticket covers it, and progression
  judges the top set.
- The bench goal isn't part of the program file. It's a lift goal set in the app.
- **Slot notes carry the program-specific cues:**
  - Bench: "same grip, setup and pause every rep".
  - RDL and pulldowns: "use straps".
  - Row: "chest on the pad, pull with the elbows".
  - Presses and curls: "control the stretch, 1 s pause at the bottom".

## The program file

The app ships this program as `app/src/main/assets/programs/full-body-3-day.json`, in the program
format (`docs/program-format.md`). `StarterProgramTest` checks it against this document. Where the
document and the format don't line up, the file does this:

- **Blocks.** Each block writes Days A, B and C in full. Ramp-in repeats Build's days with a block
  override for weeks 1–2: `rirAdd: 1` (so 0 RIR becomes 1, and nothing goes to failure) and no
  techniques. Intensify writes its lower reps into its own days.
- **Techniques on the last set.** A slot with two sets and a technique is two lines, the second
  carrying it. Myo-reps and drop sets use the format's defaults (mini-sets of 3; drops of
  25%, 2 of them). Lengthened partials go to failure.
- **Week 12, Day A.** The bench test is one line, 1 rep @ 1 RIR. Its weight is suggested from the
  estimate like any new rep range. The format prescribes no loads, so the goal rule (estimate within
  3% of the goal) is in the slot's note. The rest of Day A is written as its deload: Build's first
  sets @ 3 RIR, one set fewer, no techniques. A day override can't do this, because a day's
  `rir: 3` would also set the single to 3 RIR.
- **Week 12 is marked a deload** with a block override, `"12": { "deload": true }`, so none of its
  sets lower an estimate (the single included: it can only raise the bench estimate).
- **Week 12, Days B and C.** Build's days with a day override: `rir: 3`, no techniques,
  `fewerSets: 1`. "One set fewer" takes the last set off each slot, and a slot with one set keeps it.
- **Rest.** Main lifts (both benches, close-grip bench, hack squat, leg press, RDL, row) rest
  3:00. Pulldowns, the shoulder press and the DB incline press rest 2:00; everything else 1:30.
- **Slot notes.** Close-grip bench gets the bench note. The cable shoulder press, DB incline press
  and both curls get the press and curl note. The lateral raises, flye and calf raise have none.
- **Slot ids** are unique within a block, so Day B's lateral raise is `side_delt_raise` (Day A's is
  `lateral_raise`).
- **Not in the file**, because the app owns them: warm-ups, the "deload sets never lower the
  estimate" rule (the file only marks the week), superset rest and the bench goal.
