# Machine and cable history is kept per machine, not per exercise

For free weights, an exercise's history and estimate are shared across gyms. For machines and
cables they are kept separately for each equipment item. Stacks, pulley ratios and lb/kg plates
differ between the owner's three gyms, so "20 kg" on one cable station isn't the same load as on
another. Merging them would make progression suggest wrong weights. The cost is that a new machine
starts without a suggestion until its first logged set.
